## Design intent
Build fast, source-linked, accessible real-work editorial pages. Keep three original Instagram links and visitor-initiated embeds so third-party tracking and heavy media do not load on landing. Keep all renderings labeled as concepts. Give search engines native readable text, service links, and original case-story metadata without inventing project completion dates. Follow source attribution and privacy permission; do not upload/download/rehost private client imagery or copied Instagram media. Do not invent supplier endorsement: a screenshot comment or a stated supplier's interest in a photo is not a formal testimonial.

## Release gate
Source edits and tests are local only. Confirm embedded post display in actual browser (Meta may show login or block embeds); fallback links must still work. Verify owner approval for public changes and rights/permission to showcase client project visuals beyond the original public posts, and do not push, merge, or deploy without release authorization. Test mobile, accessibility, schema, canonical URLs, CSP, and analytics after release. Measure qualified calls and project leads against GBP baseline; rankings are not guaranteed.
